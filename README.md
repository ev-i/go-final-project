# Описание проекта
## Для чего он создан
Проект создан чтобы на практике проверить полученные знания по разработке REST backend-сервера на Go с интеграцией с базой данных SQLite
## Что он делает
Проект позволяет через веб-форму создавать, изменять, удалять, отмечать выполненными задачи в планировщике

# Список выполненных заданий со звёздочкой

- [x] Возможность определять извне порт при запуске сервера
- [x] Возможность  определять путь к файлу базы данных через переменную окружения

# Инструкция по запуску кода локально
Запуск командой
```
go run .
```
Порт по умолчанию - 7540

Адрес в браузере: [http://localhost:7540](http://localhost:7540)

# Инструкция по запуску тестов

Команда для запуска тестов
```
go test ./tests
```
